# Movie Planner 🎬

An interactive Movie and TV Show planner that calculates 
how long it takes to watch an entire series or film.
Built as part of the Full Stack MERN Developer Bootcamp 
at Matrix Master, Rotterdam.

## What it does

- Search for any movie or TV show using the TMDB API
- View poster, title and release year in a card layout
- Click "Plan it" to see total watch time
- Enter how many hours per day you can watch
- Calculates exactly how many days to finish the show!

## Example
Search "Game of Thrones" → 73 episodes × 57 min = 
4 days 21 hours → watching 2 hrs/day = finish in 35 days!

## Technologies Used

- HTML5 — semantic structure and layout
- CSS3 — dark theme, Bootstrap 5 responsive grid
- JavaScript (ES6+) — API calls, DOM manipulation, 
  dynamic rendering
- Bootstrap 5 — responsive card layout and UI components
- TMDB API — live movie and TV show data

## What I learned

- Working with a real third party REST API (TMDB)
- Making API calls using XMLHttpRequest
- Dynamically rendering cards from API response data
- Working with JSON data
- Bootstrap 5 responsive grid system
- Building interactive UI with real time calculations
- Handling API errors gracefully
- Encoding URL parameters with encodeURIComponent

## How to run

1. Clone the repository
2. Open FrontEndProject.html in your browser
3. Search for any movie or TV show
4. Click "Plan it" to see your watch time
5. Enter your daily hours to see how long it takes!
